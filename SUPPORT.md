## Nothing above helps

Open a bug report using our [issue templates](https://github.com/A-Hackers-Guide/QuestClassic/issues/new/choose). Pick "Bug report" and fill in the form; it asks for:

- Headset model + HorizonOS build (visible in System Internals panel).
- QuestClassic version (visible in the home masthead and in About).
- What you did.
- What happened.
- What you expected.
- Any buzz pattern that fired (match against [reference/buzz-patterns.md](docs/reference/buzz-patterns.md)).

## Discussion

Discussions aren't enabled yet on the repo; we'll enable them once there's traffic. Until then:

- Issues for actionable things (bugs, features).
- PRs for code.
- Everything else, drop in an issue tagged `question`.

## Security

[security/reporting.md](docs/security/reporting.md). Don't file public issues for security bugs.
